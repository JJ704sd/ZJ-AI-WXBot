# ZJ-AI-WXBot

个人微信在个微／企微混合业务群中的消息收发与受控回复可行性研究。

## 当前状态

截至 2026-09-24，文档记录了单账号、小范围真实 MVP 摘要；这些成绩尚不能归属到任何付费 SKU。目标混合群的完整收发、真实 @ 与约 300 群长期运行仍待验收。

2026-09-26 已形成 v1.21 修订版：拆分退出与停发、身份绑定与消息去重，列明 API 路线每日循环和真实模型接入的实现缺口，并统一配套讲稿与评审清单。本次是文档修订，没有新增实机成绩或核价。

本仓库跟踪的材料包括研究、脱敏证据和默认离线的 PoC，不发布原始聊天记录或账号凭据。
