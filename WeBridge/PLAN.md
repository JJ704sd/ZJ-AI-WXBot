# 微信接入执行计划

开始日期：2026-09-21。目标：个人微信测试号进入企微创建的外部混合群，主动发言、真实 @ 微信/企微成员、识别自己被 @、接收普通消息与回复。持续消息覆盖单独验收。现阶段设备只有 ARM64 Mac。

## 阶段验收

1. 环境：可重复启动；记录架构、版本、摘要；可以显示测试号登录入口。
2. 通道：普通群对照与外部混合群分别收取未 @ 消息；程序主动发送编号文本。
3. 身份：真实群 ID、个人/企微成员 ID、被 @ 原始字段；区分手打 @昵称 与真正提及。
4. 发送：分别真实 @ 两类成员，收件端确认；测试同名和改名。
5. 持续性：编号消息统计漏收/重复/乱序；断线恢复；发送超时不盲目重发。

测试号与测试群由用户准备。环境就绪后请求扫码及提供测试群定位信息，再操作确认的测试会话。正常工作的 Mac 微信与已有聊天数据不作为默认测试对象。
