# 私聊分析助手 1.1 改进计划

依据用户本轮要求：检查个微/企微私聊脚本的鲁棒性和健壮性，从实际使用出发改进交互、UI 与分析能力。延续 v1.0 的九项已确认决策及人工复核边界，不读取真实账号、不新增模型服务、不自动确认画像。

## 本轮范围与验收

1. **可靠读写**：损坏或错误类型的 JSON/JSONL 明确报错；文件大小受限；写失败不残留半成品；长操作仍在运行时不能回收其锁；不改变现有 v1 的 request/source/candidate ID 或画像格式。
2. **证据复核 UI**：把候选 JSON 改为可按主体和关键词筛选的观察列表，选择观察后查看原消息、时间、方向、来源和 ref；展示历史、限制及可能冲突。确认仍需三项人工核对，校验和保存移到后台，失败后保留窗口可重试。私聊主界面增加可见入口、材料摘要、目录/路径操作，保持客户端绑定。
3. **客观统计与检索**：只分析选定且正式复核的导出，提供全部消息/方向/类型/活跃日期及时间分布，未知时间和方向单列。统计包含表情，画像阅读材料的覆盖数另列。字面关键词搜索返回匹配条数和原消息证据，分页有限。不把频次解释为性格、关系好坏或心理结论。
4. **独立报告**：新增 insights CLI 与 Skill wrapper 模式，可导出 JSON、Markdown、自包含 HTML；输出仅到新目录，默认统计报告不复制聊天原文、不访问外网。
5. **交付兼容**：构建 1.1.0 两套 Windows Skill，实际探测版本、双客户端合成流程、原生窗口与包装脚本；保留 1.0.0 及 v41 原包。更新验收记录，既有偶发 GUI 问题不凭一次通过宣称修复。
6. **聊天时光**（用户本轮补充）：日历热度展示所选导出中的每日消息数；随机回顾一条有正文的旧消息并保留时间、方向、消息 ID 和可用 ref；“方案、下周、发你、确认”快捷检索帮助寻找约定线索。仅在桌面 UI 提供，不新增自动监控、关系评分或画像结论。未覆盖日期标为“无记录”，不推断没有联系。

## 已复现问题与修复验收

- 错误顶层 JSON、损坏 JSONL、超限文件：返回可处理错误，不静默漏读，不出现无约束读取。
- 活跃保存进程超过 60 秒：不得误删锁；写失败清理本次临时文件，原正式版本继续可用。
- 画像库/导出的祖先目录存在 Junction：拒绝路径重定向；报告也不能写入源导出或画像库。
- 企微会话只有本人或缺少明确对方映射：不进入可分析私聊列表；保留合法普通联系人及本人加单一对方映射。
- 候选复核：后台校验、后台保存；未勾选不保存，失败保留备注、重新核对后可重试；跨客户端候选在打开前拒绝。
- 检索清空、快速换词、翻页和关闭：旧请求不覆盖新结果，不继续操作已销毁控件；消息原文以字面文本显示。

## 实现边界

- 画像存储 Agent：`private_profiles.py` 与画像测试，提供只读 `ProfileStore.inspect_export(export_root)`，返回身份、覆盖范围、全部 messages、analysisRefs 和源限制，不生成请求或正式画像。
- 统计 Agent：独立 `private_insights.py` 与测试，纯统计/检索函数和新目录报告导出。
- Skill Agent：两套 Skill、wrapper、package 脚本及分发测试。
- 主 Agent：`private_profile_ui.py`、CLI/主界面接入、交互回归、最终构建与验证。

## 参考依据

参考项目 [WeChatDataAnalysis README](https://github.com/LifeArchiveProject/WeChatDataAnalysis/blob/main/README.md) 提供按时间/类型/会话导出及年度总结等功能。其[更新记录](https://github.com/LifeArchiveProject/WeChatDataAnalysis/blob/2284d8907dc1de9d8f06d5face85b77f2d5876b7/website/assets/data/changelog.json)及[关键词卡片实现](https://github.com/LifeArchiveProject/WeChatDataAnalysis/blob/2284d8907dc1de9d8f06d5face85b77f2d5876b7/src/wechat_decrypt_tool/wrapped/cards/card_05_keywords_wordcloud.py)展示结果与原文例证结合、统计卡复用读取和覆盖元数据的做法。

本轮据此改进产品交互和统计口径，独立实现，不复制外部代码。朋友圈、实时监控、自动发送、跨全部账号采集、词云语义分词和新增模型 API 不在本轮范围。
