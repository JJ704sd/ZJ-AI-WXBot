# 私聊界面美化 1.2

用户要求学习 WeChatDataAnalysis 的设计，改善现有私聊界面的视觉质量。参考已实际查看的 [聊天记录截图](https://github.com/LifeArchiveProject/WeChatDataAnalysis/blob/main/frontend/public/message.png) 与 [Modern 总结截图](https://github.com/LifeArchiveProject/WeChatDataAnalysis/blob/main/frontend/public/style1.png)：浅色底、绿色重点、侧栏层级、宽松留白和突出的文字内容。独立实现，不复制品牌、资源或源码。

## 设计与边界

- 使用现有 Windows 原生便携程序，新增私聊独立主题，不改群聊默认主题、不新增生产依赖。
- 色板：背景 #F5F7F6，卡片 #FFFFFF，正文 #17332A，次要文字 #718078，重点 #16A271，浅绿 #E8F5EE；辅助暖色 #FFF5E5。
- 正文 11pt，辅助 9pt，标题 20–24pt，数字 28–32pt。细边线、圆角面板、统一控件高度与留白。
- 主窗口：联系人、阅读、解析/复核操作有清楚分区；简化次要信息的显示，保留现有全部行为。
- 统计窗口：四项核心指标与趋势图；聊天时光为日历加回忆卡；原文检索聚焦匹配文本及证据，技术标识留在详情。
- 画像窗口：左观察列表、右原消息；新旧内容、主体与搜索可筛选；核对项仍默认未选，后台保存、失败重试保持原行为。
- 人工确认、账号绑定、统计口径、候选存储和导出格式不改变。

## 实现接口及验收

`private_theme.py` 提供颜色、字体、`apply_theme(root)`、`card(parent, padding=16, surface=...) -> (outer, inner)`、`label(parent, text=..., ...)` 及 `retheme_widgets(root)`。主题只在私聊窗口安装。所有业务按钮沿用现有回调和状态控制，保留现有 UI 测试依赖的控件属性。

按私聊主页、统计/聊天时光、画像复核三个独立区域实现。用合成数据检查常规和较小窗口布局、文字截断/重叠及异步交互，再构建并验证 1.2.0 双客户端包。保留 1.1.0 与所有旧交付，不读取真实账号。

实际验收采用原生 Tk 交互、控件与父容器边界断言及 SVG 布局预览；本轮原生桌面截图接口不可用，SVG 根据真实控件坐标生成，不作为原生截图。离线 HTML 报告另在浏览器检查。实现与结果见 `execution/private-chat-analysis-v1.2-2026-10-22.md`。
