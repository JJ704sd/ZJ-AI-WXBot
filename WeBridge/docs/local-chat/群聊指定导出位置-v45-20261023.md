# 群聊指定导出位置 v45 / Skill 1.31.0

用户已确认：选择本机目录，将群聊记录和已取得的媒体、附件保存到该目录，并记住上次位置。

实施：群聊导出区提供目录选择与路径展示；新批次在指定目录中新建独立子目录，直接逐群原子发布三格式、媒体、附件及分析材料。不覆盖已有文件，不取消人工复核。已导出文件保留原位置，目录设置作用于后续导出。私聊入口沿用原流程。

比较：内部导出后再复制会增加大数据读取和空间；只改 UI 路径会破坏恢复；选择直接发布到指定目录并保存可验证的位置引用。

配置新增可选 groupExportDirectory/groupExportRoots；旧配置默认原工作目录 exports。进度读取 v1/v2；仅包含外部导出引用时写入 version=2，保持旧文件名，v44 会明确拒绝该新进度而不会误认已完成。私聊及仅内部导出仍写 v1。正式消息与画像格式不变。

外部导出位置必须属于用户已选择并保存在配置中的目录；引用不得越界或经过链接。改目录后仍能恢复及修复旧位置的已完成结果。目录不可写、磁盘不足或发布失败时保留复核与已经完成的群，不回退到其他目录冒充成功。

验收：双端指定目录含中文路径、三格式及资产完整、目录记忆、重启恢复、跨目录后修复旧批次、取消选择无副作用、内部旧进度兼容。使用现有相关回归与少量功能测试，Windows EXE 实际合成验收；保留历史交付。
