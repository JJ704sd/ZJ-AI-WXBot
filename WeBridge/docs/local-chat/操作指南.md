# 本地微信聊天解析：操作指南

v34 的当前操作以[复核导出流程](复核导出流程.md)为准：账号加载后列出全部本地群 ID 与名称，可多选批量解析，逐群人工复核后导出。


适用版本：桌面 v34 / Skill 1.20.2，2026-10-19。企业微信客户端请先看 [企微使用说明](企微使用说明.md)：双击 `Start-WeCom.cmd` 或说“解析企微实际群名”，首次配置后复用独立设置。下文默认个微流程。

搜索框旁可一键清除搜索且保留勾选；当前群ID在阅读区顶部显示并可复制。主解析按钮只处理尚无结果或范围已变化的群，其他群复用且保留复核；独立“重新解析”会重置当前目标的复核。搜索回车只定位，不解析。底部提示未解析、未复核或可导出的下一步。小窗口会自动收起辅助说明。

界面采用紧凑排版：常规控件和正文9pt，辅助说明8pt，主标题12pt、群标题11pt；行高按本机字体度量保留空间。完成提示和状态色保留，消息列表获得更多默认阅读空间，全文分隔线仍可拖动。

## 1. 收到压缩包后怎么选

先将完整交付ZIP解压到本人可写的普通文件夹。里面有桌面包、个微Skill和企微Skill三个独立ZIP。按客户端导入对应Skill，也可同时启用两个。

| 使用方式 | 选择的文件 | 启动入口 |
| --- | --- | --- |
| 个微-本地聊天解析 | `WeChat-Archive-Skill-1.20.2-Windows-x64.zip` | 导入后说“打开个微界面让我多选群”；标识wechat-local-archive |
| 企微-本地聊天解析 | `WeCom-Archive-Skill-1.20.2-Windows-x64.zip` | 导入后说“打开企微界面让我多选群”；标识wecom-local-archive |
| 直接用桌面窗口 | 文件名含 `Desktop-v34` 或 `review-v34` 的ZIP | 完整解压后个微双击 `Start.cmd`，企微双击 `Start-WeCom.cmd` |

**不要把外层完整交付ZIP导入为Skill，也不要只复制SKILL.md或EXE。** 1.15.1起，独立Skill的Start.cmd、脚本与直接双击bin内EXE均根据runtime.json校验并绑定客户端；清单缺失、文件混用或客户端冲突会停止。旧1.15.0企微包直接双击EXE可能打开个微，请换新版。 保留独立包内所有文件、许可和校验清单。支持目标为Windows 10/11 x64；不用安装Python、pip、Docker或数据库服务。其他电脑及Windows 11的实际兼容性仍需验证。

## 2. 在WorkBuddy中使用

1. 打开“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”，选择里面的完整Skill ZIP并启用。
2. 新建任务，输入：

   > 解析示例业务群

3. 将“示例业务群”换成实际群名，无需填写程序、数据或密钥路径。
4. 可说“打开企微聊天解析界面，让我选群并人工复核，确认前不要导出”，或个微同类请求；对应Skill使用 `-Mode Desktop`。首次弹窗按下一节配置，已有配置直接复用。指定群解析后返回awaiting_review并等待人工。
5. 勾选区支持当前结果全选/取消、反选、全部群全选及全部取消；搜索保留隐藏勾选。顶部蓝色提示条显示已解析数量与最近完成群，“查看已解析群”可直接筛选定位。群列表前部显示未解析、排队中、解析中、已解析·未复核、已复核；蓝色为可阅读但未复核，绿色为已复核。批量解析时，每群完成即可立即阅读、翻页、筛选和展开转发，不用等待全部群；后台完成不会打断当前阅读。本次队列固定，期间勾选变更用于下次解析/导出。队列完成或停止后，逐群查看正文及缺口，点“复核当前群”完成四项检查和备注，再点“确认复核完成”。可人工点击“全选复核项”一次勾选当前群四项检查，或“清空勾选”；仍需点击确认才保存。列表及顶部显示未复核/已复核，可筛选所选群的复核状态。此时只保存复核，不导出；使用“下一个未复核群”切换。全部所选群复核完成后，“一键导出所选群”一次生成对应群的三格式、复核及缺口记录，“打开批次目录”查看全部结果和批次清单。失败可重试，成功群不重复导出。

导出时也可说“导出示例业务群为JSONL、JSON和MD”。每次确认导出都会同时生成三种格式，无需另外安装转换工具。宿主不提供文件呈现工具或呈现失败时，保留本地文件链接并说明，不视为已展示成功。

其他AI宿主需要支持Skill、本机命令执行及文件访问。普通网页聊天窗口仅收到Skill文件，不会自动获得这些本机能力。

## 3. 首次使用或换电脑

### 自动配置

1. 在目标电脑手动登录本人微信。
2. 工具按数据库文件的实际客户端占用关系排列账号，显示运行状态、目录及数据库数量。只有唯一运行账号时才推荐；多个运行账号先选需要的那个。登录后可点击“重新识别运行账号”，不用重新启动。
3. 点击“一键自动配置”。配置窗口在处理期间保持打开，显示进度并禁止重复提交；失败原因在原窗显示，保留输入供重试。只有校验成功才关闭配置窗口。
4. 成功后记住账号配置；已有明确群名的请求只解析该群。直接打开桌面版时，输入目标群名按Enter定位，再点击主解析按钮；完整名称优先匹配，重名时选中正确结果再点左侧解析按钮。搜索只查询群索引，启动及恢复最近群不会解析消息。

切换账号用“账号设置”；只有离线副本用“更多设置 → 手动导入数据副本”。真正换号会清除继承的密钥路径、本人身份及上次群选择；同一账号的上级目录与其 `db_storage`（个微）/`Data`（企微）目录视作同一数据源，保留已有配置。发现另一个运行账号不会自动覆盖当前已保存账号。

空白配置会先要求本人确认账号，启动目录里存在旧工作台也不会直接载入。已有本程序配置仍自动复用；需要工作台副本时，在手动页点击“使用已有工作台配置…”明确导入。

自动配置需要当前客户端、账号、数据和读取权限匹配。未登录、不支持的版本或内存布局、归属不唯一、权限不足等情况可能失败，不能保证每台电脑成功恢复密钥。只有离线密文时不能通用推导密钥。

### 已有离线副本或密钥

切换到“手动选择 / 离线副本”页。

| 选择项 | 文件或目录 | 说明 |
| --- | --- | --- |
| 微信数据目录 | 单个账号的 `xwechat_files\账号目录\db_storage` 或其上级账号目录 | 保留相关WAL、附件索引及账号旁的媒体目录，才能继续定位图片和附件 |
| 数据库密钥 | 与所选副本匹配的密钥JSON | 不是登录密码，也不是settings.local.json |
| 图片密钥 | 匹配的图片密钥JSON | 支持分开提供；数据库密钥JSON已同时包含图片密钥时可留空 |

选好后点“保存并加载”。匹配通过后才能读取记录。不要把密钥正文粘贴到对话或放进转发包。

## 4. 独立桌面版怎么操作

完整解压桌面ZIP，双击 `Start.cmd`，也可双击 `local-chat-desktop.exe`。首次配置与上节相同。

| 需要做什么 | 操作 |
| --- | --- |
| 搜索并解析目标群 | 按ID勾选一个或多个群，点“解析待处理 N 群”；搜索保留勾选，单击或双击只查看。搜索回车只定位唯一结果；无勾选时可用主按钮解析当前目标 |
| 批量选择与复制 | 空格切换当前行，Ctrl+A或“全选当前结果”勾选当前筛选结果；“清空选择”清除所有勾选；复制时每行一个群ID |
| 停止批量解析 | “停止队列”在当前群结束后停止，已完成预览保留；某群失败单独标记并继续其他群 |
| 看图 | 点击“图片总览”，再点图片放大或“定位原消息” |
| 看文件 | 选择附件消息，点“打开附件” |
| 看转发 | 在转发聊天前点箭头，逐层展开 |
| 导出记录 | 逐群保存复核后，“一键导出所选群”；“打开批次目录”看全部，本群文件入口只对应当前群 |
| 查看新增本地记录或缓存 | 在微信完成同步或下载后，点击“更新本地记录” |
| 切换账号 | 点击“账号设置”；清理旧群和旧结果入口，再搜索新账号的目标群 |

搜索不读取各群消息正文；账号准备可能需要复制、解密共享数据库，消息解析和媒体匹配仅针对确认群。找不到目标或重名时不猜选其他群。

图片和转发可在程序内查看；PDF、Office、视频附件需要电脑已有合适查看器。MD/JSON/JSONL没有默认关联时，程序会尝试系统记事本。

解析完成后，附件正文直接显示在详情、HTML、业务阅读与JSONL/JSON/MD；不再只有文件名或打开入口。原文件状态和正文状态分别标记，缺原件或扫描页不当作成功。详见 [附件正文解析说明](附件正文解析说明.md)。

## 5. 怎样理解结果和导出

`completed` 表示本次解析和阅读加载完成；`started`、`starting`、`parsing` 尚不能当作完成。`needs_source` 等待数据配置，`needs_chat` 等待确认群，`failed` 应检查具体错误。

| 输出 | 适合用途 |
| --- | --- |
| `解析结果.md` | 程序生成的固定汇报，媒体数量和附件类型以此及manifest为准 |
| `messages.jsonl` | 每行一条完整源消息，方便程序逐行处理 |
| `messages.json` | 与JSONL相同字段、顺序和嵌套结构的消息数组 |
| `messages.md` | 人工阅读，保留发送人、时间、出处、引用、转发和可用媒体链接 |
| `chat.html` / `images.html` | 离线聊天阅读页 / 图片总览 |
| `业务阅读.txt` | 保留非表情记录上下文，供人工或宿主整理业务 |
| `assets/` | 已取得并校验的图片和附件副本 |
| `manifest.json` | 条数、媒体分类、解析状态及产物摘要 |
| `media-recovery.jsonl` | 媒体缺口与本地匹配结果 |

图片的原图、缩略图、本地预览、缺失、未加载五类分开统计；附件、表情、视频和语音另计。**统计单位是普通、转发和引用中的出现次数，同一文件可能重复，不是不同图片张数。** 缺失图片没有可显示文件；缩略图只有预览，原图未取得；未加载表示尚未核查。表情缺失不阻塞业务阅读。

转移记录时，保留整个导出目录及 `assets/`。只转发MD会丢失其引用的图片和附件。JSONL/JSON保留完整原始字段，MD侧重阅读。固定汇报中的绝对本地链接指向原电脑；换电脑后从导出文件夹直接打开messages.md、chat.html或images.html。

WorkBuddy分享页与本地导出目录是不同载体，不能仅凭分享链接认定其他设备能下载本地文件；转发前按实际访问权限确认。聊天导出属于私有数据，是否转发由数据所有者决定。

## 6. 更新时怎样保留配置

桌面版与Skill共用固定用户目录，换解压目录或升级后继续复用。只搜索并解析明确确认的目标群；已有账号配置失效时保留原文件，不自动改读其他账号。

| 客户端 | 桌面与Skill默认配置和导出位置 |
| --- | --- |
| 个微 | `%LOCALAPPDATA%\LocalWechatArchive` |
| 企微 | `%LOCALAPPDATA%\LocalWeComArchive` |

固定目录无配置时自动迁移附近的有效旧配置，复制引用的密钥并保留旧文件；不同账号冲突时等待选择。旧目录不在查找范围时，在“账号设置 → 手动选择 / 离线副本 → 导入旧版配置…”选择旧settings.local.json即可。具体优先级和边界见[配置迁移说明](配置迁移说明.md)。

更换电脑或Windows用户后仍需首次配置本机账号；无需安装Python。旧合并Skill `local-wechat-archive` 应停用，保留两个独立Skill和用户目录。对外只转发原始交付ZIP，不包含使用后的配置、密钥、数据库和导出。

## 启动或初始化窗口异常

双击完整解压包的Start.cmd（桌面企微用Start-WeCom.cmd）直接运行EXE，不需要PowerShell环境初始化。配置对话框不会计时关闭：完成配置或主动关闭前会保留；成功后继续指定群解析。

主窗口点“打开诊断日志”。即使启动失败，系统提示也会显示日志位置：`%LOCALAPPDATA%\LocalChatArchiveDiagnostics\wechat` 或 `wecom` 下的startup-*.jsonl。反馈该日志即可，勿发送密钥文件、数据库、代理地址或附件正文。致命错误提示保留到用户关闭；界面操作失败可在原窗口重试。

WorkBuddy返回needs_source表示窗口等待操作；settings.local.json只在成功后生成。不得把没有设置文件视为程序已经退出。若宿主命令启动受影响，先手动双击Start.cmd完成配置，然后新建任务复用；不必修改系统代理。

## 7. 常见问题

| 情况 | 操作提示 |
| --- | --- |
| 在压缩包中双击后无法启动 | 先完整解压到本人可写目录，再双击Start.cmd；检查系统是否为支持目标的x64版本 |
| 文件被企业策略拦截或隔离 | 按组织规则交由IT处理，不关闭系统防护；当前EXE未签名 |
| 一键自动配置失败 | 查看实际错误；确认本人微信已登录、选对账号。布局不支持时使用匹配的已有副本和密钥，不反复扫描其他账号 |
| 找不到群或同名群 | 核对账号和本地副本，按实际会话ID选择；工具不会联网补拉云端历史 |
| 图片缺失或只有缩略图 | 如有权限，在微信中手动打开原图或下载，再更新本地记录；已删除、未缓存或不支持格式不能保证恢复 |
| 附件已取得但打不开 | 检查本机已有默认查看器；取得文件不代表已理解或验收其中正文 |
| 只看到MD，未看到JSONL/JSON | 核对Skill版本并重新解析，检查exportFiles和固定汇报；三种文件应位于同一导出目录 |
| WorkBuddy界面卡住 | 保留已有结果，正常重启宿主后在新任务重试；避免同时重复发起同一解析请求 |

功能边界详见随包的“个微聊天记录解析工具说明.md”，验证结论和版本信息见“版本与验证说明.md”。

## 图片刚在企微打开后的刷新

点桌面“刷新此群与媒体”，或在WorkBuddy再次说“解析企微实际群名”。新版刷新缓存索引，识别转码的本地预览；原图、缩略图、本地预览和缺失分别统计。旧导出保留，新结果在新的导出目录中。无需重新选账号或密钥。

## 选择日期与查看更多记录

在开始、结束输入框旁点“日历”，可按年月跳转后选一天，也可输入YYYY-MM-DD。点击“应用日期”重新解析当前群：阅读和三格式导出同时限定日期，结束日期包括当天，空白端点不限。点“清空”后再应用可恢复全时段。不会重选账号或取钥。

当前群默认每页300条，可选100/300/500；使用首页、上一页、下一页、末页查看。关键词框按Enter或“筛选”，可查发送人、消息、链接、转发内容和附件正文；清空关键词再筛选恢复原列表。关键词只改变当前群预览，导出仍为所选日期的完整记录。拖动列表与正文之间的横线可调整面积。

## v19 窗口位置说明

- 顶部：刷新当前群、账号设置；“更多设置”中是手动导入与诊断日志。
- 左侧：群名或ID搜索及匹配结果，只解析确认的目标群。
- 右侧上方：消息类型、关键词；点“日期 / 媒体”展开日历与媒体选项。
- 右侧中间：消息列表、完整正文和图片，图片总览在页签中。
- 记录下方：首页、上下页、末页及每页条数。
- 右侧底部：复核当前群、一键导出所选群，以及JSON、JSONL、Markdown直接查看按钮和文件所在目录。

更新后关闭旧窗口并用新入口打开，标题中的v20用于识别新版；账号配置继续复用。


## 清除账号缓存与重新配置

多人轮流使用同一台电脑，或演示首次配置时，在“账号设置”底部或“更多设置”选择“清除个微账号缓存…”或“清除企微账号缓存…”，核对客户端和清理目录后确认。请先结束解析、复核或导出操作，并关闭其他解析工具窗口。取消确认不会改动文件。

确认后删除该客户端工具的账号配置、缓存密钥、请求回执、解析副本、预览及复核缓存；未导出的复核结果也会清除。微信原始数据、已导出文件、另一客户端配置和清理目录外的历史备份均保留。清理不会退出微信客户端。

成功后界面清空并重新进入首次配置；重启新版工具也不会自动导入旧配置。人工完成新账号配置后恢复正常使用。部分文件被占用时会明确显示未完成及剩余项目，关闭其他解析工具窗口后可重试；不会把部分失败报告为清理成功。使用Skill发起的旧群解析请求会终止，重新配置后需重新发起。
