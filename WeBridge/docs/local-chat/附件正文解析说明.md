# 附件正文与状态

只处理本次指定群中已匹配、校验通过的附件，含转发和引用；不会遍历解析其他群，也不下载服务器附件。PDF与Office读取库随EXE提供，不要求安装Python、Word、Excel、PowerPoint或转换服务；打开原文件仍使用电脑已有查看器。

## 输出与兼容

原有消息、asset状态和媒体统计继续保留。新版在每个file节点增加attachmentContent，旧导出不被覆盖；需要重新解析生成正文。

- fileStatus：ready、missing、not_loaded、preview_only或integrity_error，专指原文件。
- extractionStatus：extracted（已提取）、partial（部分提取）、no_text（无文字，可能需OCR）、encrypted、unsupported、failed、too_large、timeout、budget_exceeded、original_unavailable或not_requested。
- text：正文；sections按PDF页、Word段落/表格、Excel工作表与单元格、PPT幻灯片分段。公式不执行，保留缓存值及公式文本；Excel日期可能仍为原始数值。
- source：当前群ID、根消息ID/发送人/时间/serverId、内嵌发送人/时间/part、上下文路径与数据库provenance。
- characters、truncated、notices：实际文字数量、是否截断和限制原因。

JSONL与JSON使用相同内容；MD、业务阅读、离线HTML与桌面详情同步展示正文与状态。manifest及固定汇报增加attachmentTextSummary/attachmentTextSummaryText，按引用出现次数计数。正文取不到时仍保留原件链接和原因。只复制MD也应保留assets目录。

## 格式与边界

| 格式 | 正文能力 |
| --- | --- |
| PDF | 按页提取文本层；扫描页无文字时明确标记，不做OCR |
| DOCX | 段落、表格、页眉页脚与脚注文字；不还原精确版式 |
| XLSX / XLS | 工作表、单元格地址和原始/缓存值；不计算公式，不执行宏 |
| PPTX | 按实际幻灯片顺序提取段落、表格文字和备注，不读取图形中的图片文字 |
| DOC / PPT | 常见旧二进制格式的结构化文字；标为partial，不声称图形、文本框、修订和精确版式完整 |
| TXT / CSV / MD / JSON / LOG | 本地文字；支持UTF-8及可识别的GB18030编码 |

每文件最多20MB、正文200000字符/1000段；PDF/PPTX最多100页/张。Office展开最多40MB/5000条目。每个唯一内容使用独立进程，超过15秒终止该次提取；一次导出累计最多180秒，超出明确标记。重复文件可复用提取结果，但每处原消息出处单独保存。

加密文件不尝试口令或绕过权限。扫描件、图表内图片、嵌入对象和外链不自动理解。partial/no_text与缺少原文件是不同情况，判断业务时保留这些缺口。本文档中的格式能力不等于每种真实业务文件均已实测。

构建固定使用[pypdf 6.16.1](https://pypi.org/project/pypdf/6.16.1/)、[xlrd 2.0.2](https://pypi.org/project/xlrd/2.0.2/)与[olefile 0.47](https://pypi.org/project/olefile/0.47/)，许可随包。旧DOC依据[Microsoft文本片段规范](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/01d5d8c4-cf9c-4ef9-80fd-439e763cfe01)，旧PPT依据[TextCharsAtom](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-ppt/a3c5c8d5-e530-4167-a242-7743bc99aeac)等结构读取。
