# 私聊分析助手 1.5：持续使用可靠性

基线为 1.4.0。继续沿用已确认的联系人范围、本地存储、宿主分析和人工确认流程；保留原群聊入口、历史交付与已有工作区改动。

## 本轮检查目标

1. 重复打开、并行操作和写入中断不能导致已确认画像错位或丢失；失败应能在原因消除后重试。
2. 时间、分页与统计应对应所选材料，混合时间表达和无效值不能制造错误结论。
3. 桌面错误、关闭、重试和状态切换应与实际操作一致，不能把未完成操作显示为成功或留下无法恢复的忙碌状态。

先通过公开服务接口或实际 UI 复现，再为确认的问题做最小修改。没有失败证据的区域保留现有实现。涉及新公共契约或持久化格式时先更新本 spec，不擅自扩展。

## 分工

- 存储子 Agent：`private_profiles.py` 和其专用回归；检查并发、版本发布及失败恢复。
- 统计子 Agent：`private_insights.py` 和其专用回归；检查时间、查询及统计边界。
- 界面子 Agent：`private_profile_ui.py`、`private_insights_ui.py` 及相关 UI 回归；检查关闭、失败及重试。
- 主 Agent：CLI/桌面整合、证据复核、版本构建、双端实际 EXE 与历史兼容验证。

使用隔离合成数据，不访问真实账号、聊天和密钥，不调用模型 API、不自动确认真实材料、不进行 Git 对外发布。

## 完成判据

列明实际问题和修复前后证据；定向回归与必要身份检查通过；新包逐文件摘要和 CRC 回读通过；旧交付保持原样；注明真实账号和宿主导入等未验证范围。

## 已确定的引用语义

搜索和随机回顾共享 `resolve_message_reference(source, row)`，返回消息 ID 与已验证引用。`id` 为 None 时采用 `messageId`；引用只使用 `inspect_export()` 的 `analysisRefs` 正整数映射，禁止布尔值和原消息行字段覆盖。无映射时引用为 None，仍可通过消息 ID 查看原文，不能据此伪造画像候选引用。

统计继续覆盖正式导出的完整消息；`timeRange` 是来源元数据，`observedTimeRange` 是有效消息时间实际范围，不因两者形式不同静默排除消息。

## 恢复与状态决策

- 本人总览复用现有文件锁串行发布 JSON 和 Markdown，避免并发调用交叉写入不同版本；不改变画像格式或确认入口。
- 随机回顾准备失败保留错误状态，在回顾区域说明原因并允许重新准备；不能当作空材料成功返回。
- 桌面保存回调明确返回是否接受请求。取消目录选择、主窗口忙碌或关闭时返回 False；统计窗口显示未提交。实际文件写入成功仍由主窗口异步完成后报告。
