# 群聊解密、解析与导出成功率改进 v43

基线：2026-10-22 群聊 v42 / Skill 1.28.0。目标交付：2026-10-23 v43 / Skill 1.29.0，个微和企微群聊入口。共享底层保持私聊版兼容。

## 目标与边界

提升有效数据的可读取、可解析和可导出比例，减少配置失败、单条坏消息和短暂故障造成的重复工作。成功必须来自来源校验、完整记录和可回读文件；不以跳过 MAC、WAL、SQLite 检查或隐藏缺失内容换取成功提示。

不改变人工复核后正式导出的流程，不读取真实账号聊天用于测试，不自动扩大取钥授权，不修改历史交付包。

## 实施计划

1. **数据切换可恢复**：先完成新来源的快照、模式校验和配置持久化，再切换当前会话；失败时保留原有解析、复核及恢复进度。修复手动配置窗口中加载按钮与导入按钮重叠的问题。
2. **解密范围一致**：核对用户选择的消息、附件索引和语音库范围是否完整传递到授权取钥流程；验证已选择密钥的复用路径，避免有效库被无关失效配置阻断。仅修复合成复现确认的缺陷。
3. **逐条解析保真**：检查异常时间、正文编码、结构化消息和嵌套引用的实际失败路径。可保留的原始记录必须保留其来源和原始字段；未知或部分内容有明确状态，不能标记为完整解析。
4. **导出结果验证**：覆盖正常记录与异常记录混合、多群部分失败、重启恢复、清单修复及人工确认后发布。输出 JSON/JSONL/阅读文件及清单的记录数和来源一致，已完成结果保持不变。

## 完成判据

- 每个生产修复先有失败复现，再通过回归；校验拒绝类用例继续拒绝错误密钥、损坏页面和被修改的文件。
- 不新增生产依赖，不迁移现有配置和复核状态格式。
- 执行相关源码、启动绑定、共享私聊兼容及 GUI 检查；编译后对个微、企微分别运行合成读取和导出。
- 打包 v43 并回读包内容、manifest、校验和；记录当前源码与历史包哈希，更新最新交付索引。
- 合成测试的成功率只用于描述覆盖的失败场景，不推算真实账号成功率；真实账号、真实取钥和断电场景单独标为未验证。

## 分工

- group_performance：快照与取钥范围、候选验证及合成测试。
- group_runtime：消息解析异常与导出保真、合成回归。
- group_ui：数据切换事务、配置入口可达性及 GUI 回归。
- 主 Agent：整合、交叉检查、版本、编译、交付与证据核对。

具体修复清单与验证结果在本轮执行报告中记录；未复现的猜测不作为已修复项。

## 已复现问题与处理约定

- 个微开启语音库时，原取钥清单未包含 `media_*.db`；明文与密文混合源被整体拒绝。修复为与所选范围一致，只为密文部分匹配并校验候选，全部所需密文库验证通过才保存。
- 企微原逻辑要求一个候选同时匹配全部数据库；不同库使用不同密钥时失败。改为按库匹配，并保持每个库均需验证、当前账号持有进程不变的条件。
- 个微异常本地 ID、类型或发送人编码，企微异常时间值可中断整群；企微表内秒/毫秒混存还会造成日期过滤漏行。按记录归一化，不改变原始列；无法确定的时间保留为空并列出缺口。日期过滤时仍保留时间未知行，同时明确它们不能确认属于筛选范围，不能宣称全部记录时间已验证。
- 仅当本地 ID 无法用作标识时，用来源库、表和行位置生成稳定引用；正常消息标识保持兼容。新增来源字段不迁移旧导出。
- 超大像素图片的已知解码异常仅影响该附件，媒体状态标明未取得可用预览，保留原始消息；不关闭图片像素限制。
- 新来源验证失败和设置写入失败保留旧会话与复核进度；手动配置主按钮必须能被实际鼠标命中。
