# 列群、解析、人工复核与导出（v32）

适用于个微和企微。默认业务流程：确认账号 → 展示全部本地群 ID 与名称 → 勾选群 ID → 批量解析 → 逐群保存人工复核 → 一键导出所选群的 JSON、JSONL、Markdown。

“全部”仅指当前账号本机保存的群索引和消息，不保证服务器端所有群、全量历史或当前成员完整。没有自动登录、发送、云端补拉、OCR、语音转写或外部模型调用。

## 桌面操作

1. 个微打开 `Start.cmd`，企微打开 `Start-WeCom.cmd`；在账号设置中确认数据来源。两种客户端独立保存配置。
2. 左侧勾选列支持多选；空格切换当前行勾选，Ctrl+A只勾选当前筛选结果；“全选当前结果”在全选后变为“取消全选当前结果”，勾选表头显示未选/部分/全选并可点击切换。“更多”提供取消当前结果勾选、反选当前结果、全选全部群聊（含隐藏）和取消全部勾选；Ctrl+Shift+A取消当前结果，Ctrl+I反选。“清空选择”清除全部勾选，搜索不会丢失勾选；已选数量包含隐藏群。横向滚动查看完整 ID 与解析状态；“复制所选群 ID”每行复制一个已勾选ID。同名群按 ID 区分。单击群名只切换查看，不解析；双击也不触发解析。搜索框按回车只定位唯一候选，不解析、不更改勾选；重名需按群ID确认。右侧直接显示当前群完整ID，可点“复制 ID”；左侧搜索框旁“清除”只清空搜索，保留勾选。
3. 点击“解析待处理 N 群”，仅处理尚无预览或日期/媒体范围已变化的目标群；其他群复用本窗口已有结果并保留人工复核，完成提示显示复用数量。按列表顺序逐群处理；每群完成后立即可查看，不必等整批完成。后台解析不再跳走当前阅读群，完成群可切换、翻页、筛选正文、展开转发和查看图片。队列运行时可搜索和调整勾选，本次队列及日期/媒体选项固定，勾选只影响下一次解析与导出；完成或停止后进行人工复核。未勾选时仍可解析当前高亮群。队列固定使用启动时的日期与媒体设置，期间禁止更改来源和范围；日期留空为本地完整范围，结束日包括当天。“停止队列”在当前群结束后停止，已完成结果保留；某群失败单独标记并继续其他群。默认业务阅读仅折叠表情，原始记录仍保留全部类型。所有目标已有相同范围的预览时，主按钮变为“查看待复核群”或“查看已有结果”，只定位查看。需要全部重做时使用独立的“重新解析”，它会重置当前目标的旧复核；首次未选择目标时解析按钮禁用。
4. 查看正文、发送者、图片、引用、转发、附件正文及解析状态。单击已解析群名或待复核导航切换，导航显示剩余数量，当前仅剩本群或已经完成时给出对应提示，不重新解析。此时是 `reviews/` 中的内部预览，没有正式导出。列表前部及当前群顶部显示“未复核/已复核”；可筛选所选群、所选未复核或所选已复核，筛选保留勾选。已导出仍显示已复核，底部单列其中已导出数量；重新解析、刷新或范围变化会更新对应状态提示。
5. 点击“复核当前群”，检查账号与群 ID、日期与条数、正文和结构、媒体与解析缺口。四项默认未勾选；可逐项勾选，也可人工点击“全选复核项”，用“清空勾选”取消全部，旁边显示已勾选数量。快捷按钮只作用于当前群本次窗口，不保存、不导出；不足四项时“确认复核完成”禁用。可填写备注。返回检查保留全部预览，其他群继续未复核。存在缺口时，应核对并记录可接受的范围，不能把缺口当作还原成功。
6. 在复核窗口点“确认复核完成”，仅保存该群检查项、备注和确认时间，不导出；“返回检查”不保存确认。首次复核四项均未勾选，再次通过“查看/修改复核”打开已确认群，显示本人本次会话保存的检查项与备注。修改后需再次确认才保存，其他群的复核不受影响。
7. 底部蓝色提示会说明下一步及导出按钮禁用原因，区分未解析、未复核、范围变化、可导出及已导出。所选群均已复核后，点击“一键导出所选群”。存在未解析、未复核或已失效群时不能导出；导出前校验所有目标，再复制已复核的同一批结果，不读取更新消息。
8. “打开批次目录”查看本次所有结果：根目录含batch.json和导出清单.md，每群独立子目录保留三种格式、媒体、复核记录及缺口说明。当前群的“JSON”“JSONL”“Markdown”分别直接打开相应文件；“文件所在目录”打开这三种文件保存的群目录。切换群后按钮及底部路径同步切换；未导出或缺少的文件按钮禁用，没有默认文件关联时尝试系统记事本。部分失败保留成功结果和失败清单，可重试未完成群；已导出群保留原结果并明确跳过，不重复生成。全部已导出时按钮禁用。

复用仅限本窗口同一副本、相同日期和媒体设置的结果；不自动读取新消息。需要更新本地副本时使用顶部刷新，刷新后旧复核失效。指定群启动请求和“应用日期”仍按明确目标准备新预览。

切换群保留各群的待复核批次和对应导出入口；重新解析只替换对应群的复核批次，刷新副本或切换账号使全部旧复核失效。修改当前群日期或媒体选项后需重新解析。预览文件变化、源副本变化、未完成复核或取消确认均不能发布正式结果。进程退出后不会自动恢复“已复核”状态。批量选择不合并群记录，各群分别保存 JSON、JSONL、Markdown、复核记录和缺口说明。

界面采用统一浅色配色，解析、导出和最终确认使用蓝色主按钮。窗口较矮时自动收起重复说明，保留当前群ID、复核状态、操作提示及文件入口。复核报告带可见滚动条，可按Esc返回检查；关闭或返回均不保存本次勾选。

## 命令行脚本

开发者在 WeBridge 目录运行：

```powershell
python scripts/local_chat.py review --client wechat
python scripts/local_chat.py review --client wecom
```

也可提供明确的本地数据与密钥路径：

```powershell
python scripts/local_chat.py review --client wecom --source "D:\my-account\Data" --keys "D:\private-config\database-keys.json" --data-dir ".runtime\review-session"
```

脚本先确认账号、打印全部本地群 ID 与名称，再要求输入完整群 ID 和日期；解析后打印摘要和预览目录。人工检查预览文件，逐项回答 `y`，最后输入 `EXPORT` 才发布正式结果。任一项未通过、取消或输入结束都不确认导出。已有配置失败时不会静默切换账号；普通运行不触发进程取钥。

原有开发者CLI的 `groups`、`export` 和底层批处理 `action=export` 保留兼容，不生成“人工已复核”结论。Skill的 `-Mode Export` 已拒绝，避免宿主绕过窗口复核；需要人工检查的业务使用 `review` 或桌面流程。桌面自然语言启动回执增加 `awaiting_review`，表示等待人工，只有确认并写完正式结果才为 `completed`。命名请求回执只对应原群，不随查看或导出其他群而改变；Desktop多选界面没有批量完成回执。宿主不能替用户勾选或把预览当作已确认结果。

## 数据与格式

| 内容 | 输出字段或文件 |
| --- | --- |
| 群 ID、群名、消息 ID、发送者、身份依据、时间与方向 | `chatId`、`chatName`、`id`、`senderId`、`senderName`、`senderIdentityBasis`、`timestamp`、`time`、`direction` |
| 文本、类型、链接、结构化 @、引用、转发 | `text`、`kind`、`links`、`mentions`、`quote`、`record`；未知或未支持类型保留状态 |
| 图片、语音、视频、文件与附件正文 | `asset`、`attachmentContent`、`assets/`；原件取得与正文提取状态独立 |
| 原始数据与出处 | `rawColumns`、`provenance`；跨分片记录保留，不按正文猜测去重 |
| 群成员资料 | `members.json`；本地资料，不推断历史发言者就是当前成员 |
| 完整结构化记录 | `messages.jsonl` 每行一个源消息；`messages.json` 为相同记录的数组 |
| 人工阅读 | `messages.md`、`chat.html`、`业务阅读.txt`；Markdown 与 `assets/` 一起保留 |
| 复核证据与结果摘要 | `review.json` 含账号来源指纹、群 ID、日期、统计、人工检查项、备注、确认时间和所核对文件摘要；`manifest.json` 含输出校验清单与 `humanReview` |

仅提取来源中已有的业务信息，不推测订单、报价、审批或其他业务结论。具体业务字段模板需另有已确认契约。图片/媒体缺失、未知身份、部分解析和未支持企微类型会保留状态，不能宣称已完整还原。
