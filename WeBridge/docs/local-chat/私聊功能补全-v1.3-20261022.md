# 私聊分析助手 1.3.0 功能补全

本轮基于 1.2.0，沿用 v1.0 已确认范围。目标是补齐已确认画像的桌面查阅链路，修复有合成场景证据的功能问题；保留人工复核、账号隔离及现有持久化格式。

## 实施范围

1. 桌面“更多设置”增加“查看已确认画像”和“本人沟通总览”。身份从当前会话的正式导出校验结果取得，不接受昵称推断。后台加载，展示已确认观察、原文依据、账号、联系人、版本与覆盖范围；空画像给出下一步提示。此窗口没有入库按钮。
2. 检查增量材料窗口是否提供请求、新材料和当前已确认画像；无变化时明确提示无需重复分析。
3. 检查本人总览的账号隔离、发布失败恢复，以及统计覆盖范围。只有复现后才修改；不静默跳过属于当前账号的损坏数据。
4. 复现此前的两个 GUI 超时。若为测试接口过期，修正测试契约和失败提示，保留真实的账号选择与搜索断言。
5. 画像服务的校验失败在桌面保留具体原因；未知异常继续使用通用提示。失败后可重试，且不修改正式画像。

## 分工与验收

主 Agent 负责桌面查阅入口、只读窗口、整合与交付；profile_store 负责存储和增量一致性；private_insights 负责材料窗口和统计交互；private_skills 负责旧 GUI 回归诊断。各自修改范围不重叠。

使用临时目录和合成数据验证：未确认候选不出现在查阅窗口；已确认画像可以筛选并查看消息依据；本人总览仅含所选账号的本人和关系观察；不同客户端被拒绝；窗口不提供确认写入；错误保持可恢复。修复问题先记录失败场景，再复验原场景。双端 EXE 和 Skill ZIP 实际运行、清单与哈希回读通过后交付 1.3.0；保留既有归档和版本。

真实账号读取、宿主导入和不同屏幕 DPI 组合不由合成测试代替。
