# 双击使用本地聊天解析

v21 默认流程已更新为“列出全部本地群 ID 与名称 → 按 ID 选择并解析 → 人工复核 → 确认后导出 JSON / JSONL / Markdown”。解析预览不再自动发布正式导出；四项复核默认未勾选。完整操作、命令行 `review` 入口和格式契约见[复核导出流程](docs/local-chat/复核导出流程.md)。下方旧版验证记录保留其历史范围。

这是 Windows x64 中文桌面版。运行库已放进 EXE，不需要安装 Python、Tcl/Tk、Docker、WorkBuddy 或其他插件，也不需要输入命令、配置环境变量、启动网页服务。

## 开始使用

1. 解压整个便携包，双击 **Start.cmd** 或 **local-chat-desktop.exe**。
2. 如果本机已有 WeBridge 工作台配置，程序会自动读取配置、复制并解密新的独立副本，然后显示群列表。工作台本身无需启动。
3. 在左侧选群，程序读取全部本地记录及可取得的附件，默认进入 **业务阅读**：按时间保留全部非表情记录的上下文，包括文字、引用、转发、图片附件和系统提示。窗口每页显示 100 条，用 **更早记录 / 更新记录** 查看历史；下拉框可切换全部、图片、附件、转发、引用或待补齐图片。
4. 选择消息即可在下方读全文、直接看图片；点 **放大图片** 可适应窗口或按原始尺寸滚动查看。转发聊天通过上方箭头逐层展开。缺少内嵌正文的引用会按同群来源编号及发送者信息关联原消息，可直接查看引用图片或引用的转发记录。
5. 点 **打开附件**，用系统已有的默认程序打开校验后的本地副本。程序保留原文件名；没有对应查看器时会提示无法打开。图片与转发聊天的窗口内查看不需要 Office 或浏览器。
6. 需要另存时点击 **人工复核并导出**，完成四项检查并确认。日期同时限定预览和导出，留空代表本地全部；默认包含本机已缓存附件。确认后可选择 JSONL / JSON / MD 查看文件，或打开导出目录检查原始记录、附件及 `review.json`。

快捷键：`Alt+1` 全部、`Alt+2` 图片、`Alt+3` 附件、`Alt+4` 转发聊天、`Alt+7` 业务阅读、`Alt+8` 待补齐图片、`Alt+9` 表情、`Alt+O` 打开选中附件、`Alt+V` 放大选中图片。

v6可点 **图片总览** 或同名页签，集中查看普通消息、嵌套转发及引用中的图片卡片。绿色原图、黄色缩略图、红色缺失分别标记；未加载媒体另外说明。点图片或 **查看大图** 放大，点 **定位原消息** 查看上下文。导出后可点 **打开离线图片总览**，或打开 `images.html`。按引用保留出处，同一张图可能出现多次；整份导出目录和 `assets/` 应一起保留。

v10 / Skill 1.4.1 的回执和 `manifest.json` 用 `mediaSummary` / `mediaSummaryText` 分别报告原图、缩略图、缺失及未加载图片、附件、表情。统计包含普通、转发和引用，单位为引用处数，同一文件可能重复，不是不同图片张数。旧混合媒体计数继续保留作兼容，不能据此报告图片数量。

v11 / Skill 1.4.2 新增程序生成的 `解析结果.md`，由 `reporting` 返回固定汇报及文件呈现参数。附件类型按扩展名和引用状态计算；Skill原样汇报并同时呈现JSONL、JSON、MD，避免宿主重新解释图片状态或猜测附件类型数量。

本仓库中也可双击根目录的 `打开本地聊天解析.cmd`。这个入口只调用已构建的桌面 EXE，不会下载安装任何运行环境。

## 第一次选择数据

v7首次默认打开 **自动配置（推荐）**：自动发现本机当前用户的账号目录，唯一目录自动填好；多账号先选定一个。登录本人微信后点 **一键自动配置**，先校验工具自己已保存的密钥，没有时限时尝试只读恢复所选账号的数据库与图片密钥。成功后自动继续原群解析并记住设置，用户不必寻找JSON。未登录、目录不对应、布局不支持或权限不足会明确失败；本机微信4.1.15.13已完成空白配置下恢复数据库及图片密钥、继续指定群解析的实测；另一台物理电脑仍未验收。已有文件可切到 **手动选择 / 离线副本** 页，旧流程仍可用。

便携包移到没有现有配置的新位置时，程序会显示数据设置；也可以随时点击“发现本机账号”。通过“选择…”按钮选数据目录、已有数据库密钥文件，图片密钥可按实际情况填写。也可点“使用已有工作台配置…”选择已有 `database-config.json`。

首次成功加载后，程序只记住这些文件路径和上次选中的群；以后双击会自动加载，不必重复选择。数据库密钥不等于图片密钥。可以分开选择两个文件，也可选择同时包含 `keys` 和 `imageKeys` 的组合 JSON，此时图片密钥框留空。图片密钥中的旧绝对路径只用于排序，实际通过内容校验匹配；换电脑无需编辑旧密钥文件。数据库按 salt、逐页 HMAC 与 SQLite 完整性校验，不按账号目录名猜测密钥。本人微信 ID 未提供时身份保留未知，更换数据源不会沿用旧账号的本人身份。

没有已有密钥时，可主动点“没有密钥：从本机已登录微信尝试恢复”。需要本机对应微信正在登录并持有所选账号数据；只读、限时验证唯一对应进程的候选，成功后写入程序自己的私有密钥文件。普通加载、列群和导出不会自动触发此操作。单独的加密副本没有对应进程时，不能从密文通用推导 AES 密钥；不支持的客户端布局或读取权限会明确失败。

本机使用的配置、独立副本、阅读缓存和导出位于程序旁的 **local-chat-data** 文件夹。将程序放在本人可写的普通目录中。通用分发包不包含此文件夹、任何真实密钥或聊天内容。换电脑时，需要在新电脑选择它有权读取的数据和已有密钥；运行库仍不需要安装。

自动发现会优先使用同一项目位置中的已有工作台配置；它不会遍历磁盘寻找密钥或擅自切换账号。如果上次选定的数据源失效，程序保留该选择并提示修正。源数据暂不可用但工作台旧副本仍可读取时，窗口会明确显示“既有副本，未取得新的客户端数据”，不会冒充更新成功。

## 结果与边界

导出包括 `业务阅读.txt`、全部原始记录 `messages.jsonl`、`messages.csv`、离线 `chat.html`、群成员资料、附件和校验清单。业务阅读折叠表情，保留其他记录的上下文，供人工判断业务；完整原始字段继续保留。图片缺口逐项写入 `media-recovery.jsonl`；清晰度不足或原件未取得时明确标注。

遇到未取得的图片或仅有缩略图时，程序会自动在已选择账号的消息、跨月缓存、表情存储、资源和临时媒体目录按完整内容 MD5 查找。只使用已有图片密钥处理已支持的 V2 容器；匹配后会重新读取并校验。检查上限为 20000 个文件、合计 2 GiB、单文件 100 MB，触发上限或读取失败会明确提示。点击 **更新本地记录** 可重新检查。表情包作为可选内容，缺失不阻塞业务阅读；未找到原件的图片继续保留缺口，不能据此判定它与业务无关。

引用补齐仅关联当前会话中来源编号唯一、发送者一致且可解码的原消息。找不到来源、编号重复或身份冲突时会显示缺口；引用可能补充导出日期范围之前的来源上下文。

程序只读原始数据，在程序自己的目录中制作副本和导出。刷新、预览、导出在后台执行；处理期间不会切换导出目标。关闭时会等当前本地操作结束再退出。没有客户端自动操作、进程注入、微信发送、联网下载附件或外部模型调用。仅用户主动选择的“恢复密钥”会只读访问经过归属验证的本机微信进程。

当前存储适配为微信桌面版 4.x，不能保证所有版本、私有媒体格式或未缓存附件都能还原，也不能承诺免于个微风控。语音原件、视频、WXGF 的具体覆盖和此前真实样本/合成测试区别，见 `LOCAL_CHAT.md` 与 `execution/` 中的验证记录。

历史业务样本：原始 285 条，业务阅读 264 条；8 条空白引用关联回 7 条图片来源和 1 条转发来源。19 个可用图片引用、7 个原始转发结构和 5 个附件打开回调通过窗口检查。13 个图片引用缺少原件，14 个仅有缩略图。v4 迁移与 Skill 验证及限制见 `execution/offline-chat-portable-v4-2026-10-16.md`；另一台完全干净的 Windows 机器尚未验收。

## WorkBuddy 等本机 Agent

完整 Skill v1.3.1 包含 EXE、`Start.cmd` 和 PowerShell 5.1 启动脚本。导入并启用后，在 WorkBuddy 新任务中说 **“解析示例混合群”**（或其他实际群名），Skill 默认解析全部本地记录和媒体并直接打开指定群查看。用户不用复制路径、填写 DataDir 或再次点击导出。

首次使用或换电脑时，在弹出的窗口选择本机数据和匹配密钥，点“保存并加载”，刚才的群请求会自动继续，不必重发指令。选择保存在当前 Windows 用户 `%LOCALAPPDATA%\LocalWechatArchive`，与技能安装位置及版本分离，之后自动复用。更换账号仍可在窗口点“数据设置”；没有匹配密钥时不会假报已读取。

只有收到 `completed` 状态才表示解析与阅读加载完成；启动脚本返回 `started` 时窗口仍在处理。完成回执包含本次群名、条数、保存位置；同名或不存在的群在窗口中选择，不会自动跳到上次群。程序和 Skill 更新不需安装 Python，包内运行库按版本保存，避免覆盖正在使用的旧 EXE。

解压后仍可双击 `Start.cmd` 打开工具。Skill 还支持单独列群、日期过滤导出及用户主动选择的本机取钥；高级选项见 Skill 内说明。只有 SKILL.md 而没有包内运行文件时不能运行。v5 本地短入口实测与宿主自然语言触发的边界见 `execution/offline-chat-short-launch-v5-2026-10-16.md`。

## 开发者构建

现有 CLI 入口继续保留。桌面版复用相同解析代码，Tcl/Tk 窗口组件和 Pillow 12.3.0 图片组件随 EXE 打包；排除不需要的 NumPy 和 Qt 组件。构建依赖只放在开发者项目目录，使用者无需安装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_local_chat.ps1 -Desktop -OutputDirectory build/local-chat-desktop-v5
python scripts/package_local_chat.py --desktop --binary build/local-chat-desktop-v5/local-chat-desktop.exe --output build/local-chat-desktop-windows-x64-批次名
python scripts/package_local_chat_skill.py --desktop-package build/local-chat-desktop-windows-x64-批次名 --output build/local-wechat-archive-批次名
```

Tcl/Tk 构建资源必须在构建机可读，否则构建会提前停止。无需在使用者电脑配置这些资源。许可证随包附带；Tcl 文本来自 [Tcl 8.6.15 官方源码](https://github.com/tcltk/tcl/blob/core-8-6-15/license.terms)。
