# 私聊分析助手 1.1.0 改进与验证

本轮依据用户的鲁棒性、功能交互、UI 与趣味实用功能要求，延续已确认的私聊画像契约。本地开发与验证完成于 2026-10-22，未读取真实账号、私聊、密钥或运行取钥流程，未提交或推送 Git。

## 本轮改进

| 使用问题 | 结果 |
| --- | --- |
| 错误类型或损坏 JSON/JSONL 被遗漏，CLI 可能抛异常 | 顶层对象、逐行结构、深层嵌套及文件大小校验；损坏材料明确失败 |
| 检查文件大小后，文件继续增长 | JSON/JSONL 有界读取，摘要分块计算并计数；Markdown 保留 Windows 换行兼容 |
| 长操作的锁被当作陈旧锁 | 只有达到陈旧时间且持有进程明确不存在时才回收；失败释放资源 |
| 父级目录 Junction 重定向 | 根目录、祖先目录、存储文件与锁路径均检查；报告拒绝写进正式导出或画像库 |
| 企微只有本人、缺少对方或成员歧义 | 不进入可分析私聊列表；普通联系人映射及本人加单一对方映射仍可用 |
| 整块候选 JSON 难以复核，保存阻塞窗口 | 主体/关键词筛选、新观察/历史切换、逐条原文证据、差异提示；后台校验和保存，失败保留备注并允许重新确认 |
| 私聊功能藏在更多设置中 | 主界面增加统计检索、准备材料、候选复核入口；客户端绑定在打开候选前检查 |
| 分析缺少客观概览 | 方向、类型、活跃日、日/月/小时分布，时间和解析缺口；包含表情，画像阅读覆盖数单列 |
| 界面过于机械 | “我们的聊天足迹”、月度日历热度、随机旧消息回顾、方案/下周/发你/确认快捷检索 |
| 大量命中时重复复制正文 | 检索仅整理当前页，随机回顾缓存原消息引用；后台搜索，清空和关闭废弃旧结果 |

聊天时光只使用当前选定且正式复核的导出。无记录日期明确标为“本次导出没有该日记录”；关键词命中是线索，不自动认定为承诺。画像仍由宿主分析，候选仍由用户确认入库，未增加关系评分、自动监控或模型 API。

报告支持新目录中的 `summary.json`、`report.md`、`report.html`。HTML 自包含、文本转义、无外部资源；默认不复制消息正文，但包含联系人、客户端、复核标识和来源摘要。源导出与画像库仍需一并保留备份。

回归曾发现有界 Markdown 读取改变 Windows 换行比较行为，已恢复原有 universal-newline 语义并重跑通过。Tk 测试对象在主线程清理，避免组合测试结束后在工作线程回收 Tcl 对象。中间写入状态和失败运行不计作通过证据。

10 万条纯合成消息的内存统计/检索测试：总量和末页断言通过；启用 `tracemalloc` 时统计 6.671 秒、检索 0.202 秒，额外峰值分别约 6.90 MiB / 0.81 MiB。仅衡量内存模块，不代表数据库解析、导出校验、真实聊天或 UI 渲染性能。数据见 `private11-synthetic-performance.json`。

原生窗口截图仅含合成数据：`private11-chat-time.png`、`private11-profile-review.png`。已检查日历颜色层级、原文显示、确认初始禁用状态及主要控件可见性。

## 实际 Windows 包验证

打包器实际执行桌面与画像 EXE 能力探针，检查角色、direct 模式及 1.1.0 版本。每端 ZIP 27 个文件，CRC、完整文件集合、逐文件 SHA-256 及 runtime 摘要均通过。包内没有数据库、聊天 JSONL、真实配置或密钥。

双客户端实际 EXE 已验证：合成私聊解析、prepare/stage/show、中文候选往返、PowerShell wrapper、insights 统计与报告、关键词分页、拒绝污染源导出、拒绝跨客户端调用，以及隔离空配置的原生窗口启动。子进程 PATH 不含 Python。空配置回执为“需要配置账号”，不是账号连接成功。

同一份正式合成导出分别交给 1.0.0 和 1.1.0 实际画像 EXE，requestId 和 sourceId 一致；未确认候选不创建正式画像。完整结果见 `private-analysis-1.1.0-compiled-validation.json`。

## 使用边界与尚未验证

- 未执行真实账号数据库覆盖验证或 WorkBuddy 导入、模型分析；真人画像准确性不由合成测试证明。
- 继续使用现有解析器支持的本地数据库版本；企微内部/外部联系人的类别缺乏证据时保留未知。
- 当前材料校验限制：每个文件 64 MiB、整个正式导出 1 GiB、20,000 个文件、JSONL 500,000 行；超限明确拒绝。大量媒体可在人工复核阶段选择不复制媒体后重新导出，不可直接删改正式导出。
- 目录路径校验不能等价于操作系统级锁定；外部进程同时替换路径仍属未覆盖的本地文件系统竞态。
- 本轮没有新增生产依赖、云服务、自动发消息或定时任务。
