# 私聊分析助手 1.3.0：功能补全与验证

本轮基于 1.2.0，按 `docs/local-chat/私聊功能补全-v1.3-20261022.md` 实施。主 Agent 整合桌面查阅入口，三个子 Agent 分别检查存储、材料窗口和历史 GUI 回归。

## 已补充与修复

- 桌面“更多设置”增加“查看已确认画像”和“本人沟通总览”。选中已有正式导出的联系人后，后台校验导出并取得客户端、账号和联系人身份；查阅窗口可以筛选观察、查看消息证据、账号、版本与覆盖范围。窗口只展示已确认数据，没有入库操作。本人总览只汇编所选账号的本人/关系观察。
- 增量材料窗口补齐 `currentProfileFile`，复制路径时包含已确认基线、请求和阅读材料；长路径和多分段材料支持双向滚动。材料没有变化时明确提示无需生成候选。
- `stage()` 拒绝 `unchanged` 请求，避免重复生成空候选及多余版本。人工确认、已有历史版本和存储格式保持兼容。
- 正式导出的覆盖时间以完整消息集合计算，包含首尾的表情、媒体等非分析消息。
- 本人总览仅深度校验当前客户端和账号的版本内容。其他账号的版本文件损坏不再阻断当前账号；指针身份无法读取、目录不匹配、当前账号数据损坏仍明确报错，不静默丢失数据。总览写入失败回滚场景已验证。
- 桌面保留画像服务明确给出的校验原因，例如版本摘要不一致；不再误报为数据目录/密钥错误。合成篡改场景验证失败后退出忙碌状态，恢复原文件后可以重试。
- 修正两个历史 GUI 测试：一个替身没有接受 `bootstrap(resume=...)`，另一个仍假设搜索回车会自动解析，并沿用旧的复核/导出流程。保留搜索不读取正文、显式解析、默认未勾选复核、确认后导出等实际断言。没有通过放宽超时来掩盖异常。

## 验证证据

本轮 80 项不同的定向用例通过（重复复验不重复计数）：核心 53 项；原生界面、双端集成、布局、已确认画像菜单与查看 20 项；旧 GUI 所属测试 6 项；原有群聊复核复用与显式重解析 1 项。运行身份扫描 119 个文件，0 个问题。另有 `py_compile` 与 Git 已跟踪差异空白检查通过。

修复前已复现：缺少增量画像基线路径、无变化请求可继续 stage、统计覆盖漏掉非分析消息、其他账号损坏阻断总览；新增桌面查阅服务在实现前的合成测试失败。修复后分别验证原场景、正式画像读取、未确认候选隔离、账号与客户端绑定、窗口无保存操作、消息依据可见及后台加载。

日志保存在 `.runtime/private13-core-tests.log`、`private13-native-tests.log`、`private13-final-ui-tests.log`、`private13-final-material-tests.log`、`private13-old-gui-regression.log`、`private13-group-regression.log`。具体错误丢失的修复前记录为 `private13-error-red.log`；最终 EXE 日志为 `private13-compiled-final-tests.log`。双端实际包结果见 `private-analysis-1.3.0-compiled-validation.json`。

## Windows 交付验证

使用现有项目依赖重建两个 EXE，没有新增生产依赖。每端 Skill ZIP 27 个文件；以隔离临时账号与合成消息实际运行 EXE，验证私聊解析、人工复核后的导出、prepare/stage/show、中文候选、PowerShell wrapper、统计报告、关键词分页、禁止写入源目录、跨客户端拒绝，以及空配置下的原生窗口启动。子进程 PATH 不包含 Python。

另在独立临时库用测试 API 建立已确认合成画像，再用实际 EXE 验证已确认画像读取、本人总览和 `unchanged` 请求拒重；未确认库仍无正式画像，分发 CLI 未增加无人值守确认入口。两个客户端的请求与来源 ID 均与 1.0.0 实际 EXE 生成结果一致。

包的文件集合、CRC 和逐文件 SHA-256 回读通过。交付合集及此前 13 个 ZIP 的保留验证见 `private13-delivery-validation.json`。源代码清单摘要见 `private13-source-manifest.json`。
