## 检查发现与处理

| 发现 | 处理与证据 |
| --- | --- |
| `server.py` 无条件导入 `fcntl`，Windows 导入失败 | 使用 Windows `msvcrt` / Unix `fcntl` 进程锁；互斥与释放测试通过 |
| SQLite 上下文只提交、不关闭连接，Windows 删除临时数据库时报 WinError 32 | 连接明确 commit / rollback / close；回归启用 ResourceWarning 错误检查 |
| Windows 可能缺少 IANA 时区数据库 | Asia/Shanghai 不可用时采用固定 UTC+8，保持每日调度当前时区契约 |
| 仅有 Mac Shell 启动入口 | 增加 CMD + PowerShell 启停、Python / 端口 / 运行目录权限预检、进程归属核对 |
| 服务失联仍显示连接，切群清空草稿，提交期间可重复操作 | 状态失联同步更新、账号与群隔离的会话草稿、提交互斥与保留提交中的新编辑 |
| 退出后旧轮询结果可能恢复旧账号连接状态 | 可重复并发用例先失败；连接代次校验后通过 |
| 连接代次修复使后台账号轮询丢弃正在进行的手动群列表刷新 | 分离账号和群列表请求代次；修前失败、修后通过，并验证旧群查询不能覆盖新查询 |
| 实际运行能力与“模式支持能力”混淆 | `supportsLiveSend` 与当前 `canSend` / `liveSend` / `connected` 分开；未连接不标记可发送 |
| 不同 Windows 账户的私有运行目录不能互相使用 | 发现隔离测试账户创建的目录阻止当前用户启动；归档本次合成 QA 目录后重新启动成功，并增加权限预检及可操作错误提示，没有放宽 ACL |
| 原生预览离页后残留 DOM 文字，迟到响应会恢复已经清除的结果 | 离页、隐藏页面、换窗、清除时销毁文字并递增请求代次；失败后必须重新检测 |
| `GetWindowRect` 含不可见缩放边框，可能误拒绝最大化 / 贴边窗口 | 截图及遮挡判断改用 DWM 可见边界；不可获取时失败；纯几何测试覆盖贴边、多屏和一像素遮挡 |
| 切群加载期间能保存尚未读取的空白回复规则 | 群资料就绪前禁用提交；旧请求不能覆盖新选中群或规则 |
| 定时页统计混入手动 / 回复消息，无变化轮询销毁键盘焦点 | 只统计 schedule 来源，注明最近记录范围；停用任务不再显示下次执行，无变化不重建任务按钮 |
