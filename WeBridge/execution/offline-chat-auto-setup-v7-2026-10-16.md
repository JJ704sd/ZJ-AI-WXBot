# v7 首次自动配置与密钥来源说明

日期：2026-10-16。桌面程序 v7 / Skill 1.3.0。

## 密钥来源

数据库和图片密钥JSON由此前恢复脚本生成，并非微信默认导出，也不是用登录密码推导。历史2026-09-28媒体验收记录显示，6个数据库密钥匹配，两份独立V2图片样本通过解码验证。当前脚本分别为 `scripts/acquire_database_keys.py` 和 `scripts/acquire_image_key.py`；候选经验证后才写入私有文件。

## 新版行为

- 首次只做当前用户路径发现，不全盘搜索、不读取进程内存。常见目录、实际Windows文档目录和可读的微信目录配置提示可作为候选。
- 唯一账号自动填好，多账号必须由用户选定。目录标签不是已验证账号身份。
- 用户点“一键自动配置”后，先校验明确引用或本程序 `keys/` 中最多16个已有密钥文件，没有可用文件时才为本次操作调用受限的只读恢复组件。
- 数据库密钥通过副本校验、成功加载后才保存设置；图片密钥可一同写进组合JSON。图片恢复失败不会假报图片完整。
- 未运行微信、账号/目录不对应、归属不唯一、布局不支持、权限不足、超时均保留具体原因。不自动登录、切换账号、关闭防护或循环重试。
- 首次窗口分为“自动配置（推荐）”与“手动选择 / 离线副本”。旧设置格式与手动入口兼容，没有新增使用端依赖。
