# 私聊分析助手 1.6.0 · 宿主分析与桌面复核衔接

基于 1.5.0，先编写 spec，再分配材料窗口、桌面入口和真实 ProfileStore 合成验证三个独立子任务，主 Agent 负责服务绑定、整合和交付。

## 本轮结果

- 材料窗口可复制完整分析任务，包含所选请求、基线、必要材料路径、三类画像目标和候选规则；聊天正文不写入任务模板。
- 用户可以直接导入宿主生成的 JSON，程序校验并暂存后打开现有人工复核窗口，无需先手工执行暂存命令。旧 CLI 和画像库候选入口继续保留。
- 导入先核对已复核导出和请求中的客户端、账号、联系人；材料窗口还绑定请求 ID。主菜单允许同一身份的其他有效批次，证据和基线仍按原请求校验。
- 文件选择前后检查当前会话和忙碌/关闭状态。取消时明确显示未提交；错误 JSON 修正后可重试；窗口关闭后回调安全结束。无变化材料不生成重复候选。
- 复制操作给出成功提示，按钮分为两行，620px 最小窗口下通过实际 Tk 坐标边界断言。

导入仅暂存，不自动确认画像。正式入库与跨端身份关联继续由用户确认。没有修改画像持久化 schema，也没有新增生产依赖。

## 验证范围与使用

全部业务数据均为隔离合成材料。未验证真实账号、WorkBuddy 等宿主的实际导入/分析、所有 DPI 组合或全仓全部测试；实际 EXE 验证不等于真实业务验收。没有对外发布或 Git 提交。

解压对应客户端 ZIP 到新目录，运行 Start.cmd。完成当前私聊的人工复核导出后，选择“准备画像材料”→“复制分析任务”；把宿主生成的 JSON 用“导入候选并复核”导入。正式导出与本地画像库需一并保留。
