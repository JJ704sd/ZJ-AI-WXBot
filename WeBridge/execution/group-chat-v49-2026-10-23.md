# 群聊 v49 / Skill 1.35.0 验证记录

2026-10-23。在 v48 上修复仍可复现的原件漏检和预览正文损失，减少按消息反复查找同一个文件。个微与企微使用同一套导出校验；未增加生产依赖。

## 缺陷、影响与处理

| 缺陷或缺口 | 对实际使用的影响 | v49 结果 |
| --- | --- | --- |
| 个微兜底默认最多20000文件/2GiB，普通单文件100MiB，每群重新读取摘要 | 本地存在也可能漏掉；大批群重复扫描耗时 | 取消默认文件数/累计字节配额，完整扫描所选账号媒体目录；复用未变化普通文件的摘要，变动后刷新 |
| 双端普通原件受100MiB限制，整文件读取 | 已缓存大附件仍导不出，内存随文件增大 | 普通原件流式校验和落盘，不再受100MiB限制；摘要匹配且复制期间文件未变化才发布 |
| 本地预览有可读文字但直接跳过OCR | 截图、报价图已有信息不能进入分析材料 | 开启图片OCR后识别可用预览；标注预览、部分正文、待复核，原图缺口仍保留 |
| 缺口逐条引用列出 | 同一个原件重复查找、下载；重要附件被淹没 | 按原件MD5归并清单，附件优先、重复引用多的优先；保留群、时间和消息定位；无摘要不按同名合并 |
| “已导出/解码成功”被等同于内容齐全 | 分析漏掉截图条件、引用关系或未适配正文 | 完整性概览区分原件、预览OCR、正文和缺口，新增“按文件补原件”入口；解码状态不表示业务准确率 |
| 未缓存原件、未知密码和未适配消息结构 | 无法据现有材料还原全文 | 仍为待补缺口；不能从预览生成原图，不能把未知字段当可靠正文 |

保留与正确性直接相关的账号归属、路径边界、文件摘要与发布校验。没有新增通用重试层、审批步骤或网络协议猜测。解码图片容器100MiB、正文提取20MiB等限制与普通原件归档分开，超限时原件仍可保留、正文原因单独记录。

## 实际执行

- 160项核心检查、32项原生GUI检查通过，零失败、零错误、零跳过。核心检查后补充视频无后缀的回归，最终媒体定向6项再次全部通过；这6项与核心检查有重叠，不相加为独立用例数。
- 首轮GUI曾有4项交互断言失败；同组期间另有原生界面预览运行。停止并发界面操作后，4项隔离复核及完整32项串行复验通过，未修改相关生产逻辑。并发焦点干扰是可能原因，未证明为唯一根因；初轮与复验日志均保留在本地。
- 源码身份扫描128个文件通过，git diff --check通过。合成完整性概览截图核对了按钮和统计布局。
- 三份独立ZIP均完成文件清单、SHA256与读取校验。最终个微、企微Skill EXE各自读取合成数据库，验证101MiB原件实际落盘及摘要、预览OCR文字及原图缺口、按原件归并清单。
- 同时复验已知密码PDF/Office、混合PDF、Office内嵌图片、多页TIFF、错误后缀图片、OCR行定位、JSON/JSONL一致性、Markdown消息ID、分析材料和导出文件摘要。密码没有进入导出文本。原生界面仍等待用户复核，未自动发布到所选正式目录。
- 35个历史ZIP摘要保持不变，包括v48及私聊1.7.0。私聊独立交付版本不变。

详细机器可读结果见同目录group49-core-validation.json、group49-gui-validation.json、group49-final-media-validation.json及group49-compiled-validation.json；源码清单为group49-source-manifest.json。

## 真实旧包核查与可立即使用的材料

只读扫描用户此前导出的117群、1,142,819条记录，源ZIP摘要未变。

- 按旧导出中的媒体状态，20,399处缺少原件或仅有预览的引用归并为12,878项待补任务，其中17项无可靠原件摘要，保留为独立发生项。这是旧包范围的跨群清单，不是本轮重新检索当前缓存的结果。
- 从旧包提取1,020份去重图片预览，校验文件后实际运行Windows本机OCR：775份有文字、245份未识别到文字，批次与完整性失败均为0。增补材料保留图片、群/消息/时间定位和预览标记；不代表取得了775份原图或文字完全准确。
- 旧版12,125条未适配类型中，7,599条已被v46以后既有规则识别，4,526条仍未适配；这是对现有规则的复核，不是v49新增了7,599条适配。新增识别出的媒体节点仍需重新解析检查原件。

真实聊天、图片和OCR正文仅保存在用户本机outputs目录，不进入公开交付ZIP。本报告只保留聚合数字。

## 未解决与验证边界

客户端缓存和补充目录都没有原件时，需要在客户端打开/下载或取得备份后补入；没有实现自动从服务器取回任意未缓存原件。未知密码不猜测。扫描数字、单位、小字、表格关系需要对照图片复核；OCR不是可靠表格重建，混合PDF重复文字不能计为两笔业务。

缺少可信原消息ID时，引用文字可读也不等于已建立原消息关联；不得把零关联解释为无人回复。跨群相同询价是否为同一订单仍需按业务证据归并。剩余未适配类型保留原始字段和缺口，未声称完整还原。

本轮没有重新导出真实账号全量历史，无法给出新的全量原件恢复率；合成EXE检查不代表真实账号成功率。未实测WorkBuddy导入、硬件断电或另一台物理机。以上为定向检查，非全仓测试。
