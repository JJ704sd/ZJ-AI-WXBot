# 私聊分析助手 1.7.0 · 界面与导出恢复

基于 1.6.0，先写 spec，再分配统计界面、画像界面、导出恢复任务；独立审查发现联系人映射校验缺口，已修复并复测。

## 本轮改动

- 主页突出“解析记录 → 复核导出 → 分析画像”；会话资料按需展开，长名称按可用宽度缩略，空状态给出下一步。保存位置、打开文件、修复清单入口可直接找到。
- 聊天足迹减少多层标签，指标补充含义，材料窗口明确复制任务与导入候选顺序。
- 画像阅读区区分观察、消息依据和技术出处；空搜索提供返回提示，超长证据在写入控件前限制长度。
- 重新解析或保存新进度失败保留原复核；已完成导出写入恢复记录，重启核对账号、联系人、日期、人工复核及文件摘要后恢复。
- 一项发布失败不影响其他已完成会话；重启后跳过已完成项，只重试未完成会话。目标目录不存在的发布意图可恢复为已复核待导出。
- 清单文件采用临时写入和原子替换。清单失败明确区分“正文已保存”和“清单待修复”；修复只重建当前来源已验证结果的清单，不重写正文，未完成会话继续列出。
- 恢复将导出正文与复核时摘要对照；即使正文及 manifest 同步改写，也拒绝恢复为已完成。私聊身份还须匹配快照的联系人映射。
- Windows 旧锁持有者检查改为只读查询进程句柄，不调用会发送控制台中断信号的 os.kill(pid, 0)；权限不明时保留锁，避免误回收。详见 [Python 定义](https://docs.python.org/3.14/library/os.html#os.kill) 与 [Microsoft 等待接口](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-waitforsingleobject)。

没有新增生产依赖，没有改变正式画像或正式导出的持久化格式。复用 v1 checkpoint 字段保存已发布项；人工确认和跨端身份关联仍按原流程。

- 核心、导出恢复、身份与既有群聊后端：81 项通过；画像存储独立回归 29 项通过；双端原生整合 8 项通过。
- 原生 Tk、材料/画像交互、私聊布局与既有群聊交互：57 项通过；末轮补充桌面重新解析失败保留结果 1 项通过。
- 合计 176 项独立定向用例通过，无跳过；中间重复复测不累计。
- runtime identity 探针通过，119 文件无问题；两套 Skill 的官方 quick_validate 在 UTF-8 模式通过。
- 双端实际 EXE：隔离合成解析、prepare/stage/show、统计报告、中文、PowerShell wrapper、客户端绑定和空配置原生启动通过；陈旧时间戳但持有者存活的画像锁会超时拒绝，原锁保留且没有控制台中断。
- 旧版升级：1.0 持久标识与 1.2→1.7 请求/候选兼容通过，旧请求与候选字节不变。
- 两个单端 ZIP 各 27 文件，逐文件 SHA-256、CRC 回读通过；25 个历史 ZIP 哈希不变。
- 10 份布局预览根据实际 Tk 控件位置和合成文字生成 SVG，经浏览器查看；不是桌面截图，原生文字换行、边框和焦点可能存在差异。布局断言使用实际 Tk 坐标。

故障注入覆盖解析失败、进度及设置写入失败、批次索引/说明写入失败、部分会话发布失败与重启重试、正文篡改、联系人映射篡改及快照变更。正式 EXE 验证不包括进程强杀、磁盘故障注入或硬件断电；这些边界未作成功声明。

中间运行曾出现未完整写出结果、测试脚本导入路径错误，以及 Windows 短路径/长路径的测试断言差异；这些运行不计为通过。异步 KeyboardInterrupt 最终定位到 Windows 旧锁检测的信号调用并修复，不能归因于机器资源压力。最终按日志中的完整结尾核对结果。Junction 测试改为进程内创建真实 Windows Junction，保留实际路径边界检查；此项仅改变测试。

## 使用与限制

解压对应客户端 ZIP 到新目录，运行 Start.cmd。请保留原工作目录缓存、正式导出和画像库。恢复沿用原快照；读取新消息需手动刷新并解析，刷新会重新建立本轮进度。若快照、复核缓存或导出文件被修改/移走，恢复会停止，并保留已落盘的正式导出。

这是会话级恢复，未完成会话从文件复制步骤重新执行，不是单个大文件字节级续传，也不保证硬件断电持久性。全部验证使用隔离合成材料，未验证真实账号、WorkBuddy 实际运行、所有 DPI 或全仓全部测试。未对外发布或 Git 提交。
