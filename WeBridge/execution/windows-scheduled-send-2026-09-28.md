# Windows 定时发送

## 工作台操作

左侧进入“定时任务”，点击新建；也可以在聊天页输入正文后点击“定时发送”。

- 选择已勾选读取的个人会话或群聊。
- 选择“指定日期发送一次”“每天固定时间”或“按星期重复”，全部按北京时间 UTC+8。按星期重复时明确勾选执行日，新建窗口预选周一至周五，可自行调整。
- 设置计划时间起的执行窗口，整数 1～1439 分钟，默认 2 分钟；列表显示实际窗口。窗口允许跨午夜，仍属于计划日。
- 填写完整文本，点击“创建并启用”。Windows 当前仅支持普通文本，不支持定时附件或原生 @ 成员。
- 列表显示目标、正文、计划时间、下次运行和最近 10 次执行记录；支持暂停、恢复和取消。

一次性时间须晚于当前时间；重复任务取严格晚于当前时刻的下一个执行日。修改目标、正文、执行日或窗口请取消旧任务后新建。取消不撤回已经提交给微信的消息。

统一话术可在“模板库”保存，使用 `{{变量名}}` 为不同会话填写变量，也可保存某个会话独立使用的完整正文。新建任务时点击“从模板填入”，预览并明确应用，之后仍可人工修改正文。保存和预览不会创建任务；模板修改或删除也不会改变已有任务。具体限制与验证见 [模板与会话配置说明](workbench-schedule-templates-2026-10-03.md)。

需要停止一组任务时，在会话筛选中选择“全部会话”或指定会话，然后点击“暂停全部定时任务”或“暂停本会话任务”。范围以当前账号和会话选择为准，不受关键词或状态筛选影响；已经取消读取的会话仍可暂停。只暂停定时任务，自动回复与人工待办独立。当前已开始处理的一条仍可能提交，已提交内容不撤回；恢复仍须逐条操作。详见 [批量暂停说明](workbench-schedule-pause-2026-10-03.md)。

## 运行语义

任务保存在本机运行目录 `windows-schedules.sqlite`，独立于旧 Linux / Demo 的任务表。没有新增生产依赖。

关闭网页不会停止任务，但工作台后台、微信及 Hook 需运行。主循环约每 2 秒检查一次；副本正在更新时等待，不提供硬实时保证。

每次运行以任务 ID 和计划时刻持久化领取，再调用已有 Hook 发送入口。创建请求有幂等标识；同一计划不会重复提交，网络结果未知不重试。结果栏区分“调用发送入口”“服务器接受”和“结果未知”，均不等同收件端确认。

超过配置的执行窗口则跳过，默认仍为计划后 2 分钟，不补发过期消息。每日任务持续启用但跨日漏执行时，每个错过的执行日分别入账；当天仍在窗口内，则仅执行当天一次，再安排未来的下一次。消息读取、Hook 探测和账本写入后会在本机提交前再次核对截止时间；已开始提交后的晚返回保留实际结果。一次性任务结束后不能再次恢复发送。配置、兼容性与截止检查见 [执行窗口说明](workbench-schedule-windows-2026-10-03.md)。

按星期重复使用配置窗口，仅为选中的日期生成执行记录；星期按计划时刻的北京时间日期确定。例如周五 23:59 的默认 2 分钟计划在周六 00:00 仍处于周五该次的允许窗口。暂停及重启后恢复仍只安排未来的选中日期。接口、兼容性及合成验证见 [每周计划说明](workbench-weekly-schedules-2026-10-03.md)。

断线、账号/进程变化、取消收件会话读取、主动断开 Hook 或重启工作台会暂停任务。恢复时重新验证账号及 Hook；每日任务重新计算未来时间，一次性任务必须尚未过期且没有领取记录。未知结果的一次性任务不可重试；每日任务恢复只影响未来计划。
