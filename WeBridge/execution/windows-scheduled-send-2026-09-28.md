# Windows 定时发送

## 工作台操作

左侧进入“定时任务”，点击新建；也可以在聊天页输入正文后点击“定时发送”。

- 选择已勾选读取的个人会话或群聊。
- 选择“指定日期发送一次”或“每天固定时间”，全部按北京时间 UTC+8。
- 填写完整文本，点击“创建并启用”。Windows 当前仅支持普通文本，不支持定时附件或原生 @ 成员。
- 列表显示目标、正文、计划时间、下次运行和最近 10 次执行记录；支持暂停、恢复和取消。

一次性时间须晚于当前时间；每日时间已经过去时，从下一天开始。修改目标或正文请取消旧任务后新建。取消不撤回已经提交给微信的消息。

## 运行语义

任务保存在本机运行目录 `windows-schedules.sqlite`，独立于旧 Linux / Demo 的任务表。没有新增生产依赖。

关闭网页不会停止任务，但工作台后台、微信及 Hook 需运行。主循环约每 2 秒检查一次；副本正在更新时等待，不提供硬实时保证。

每次运行以任务 ID 和计划时刻持久化领取，再调用已有 Hook 发送入口。创建请求有幂等标识；同一计划不会重复提交，网络结果未知不重试。结果栏区分“调用发送入口”“服务器接受”和“结果未知”，均不等同收件端确认。

超过计划时间 2 分钟则跳过，不补发过期消息。每日任务持续启用但跨日漏执行时，每个错过的执行日分别入账；当天仍在 120 秒窗口内，则仅执行当天一次，再安排未来的下一次。一次性任务结束后不能再次恢复发送。

断线、账号/进程变化、取消收件会话读取、主动断开 Hook 或重启工作台会暂停任务。恢复时重新验证账号及 Hook；每日任务重新计算未来时间，一次性任务必须尚未过期且没有领取记录。未知结果的一次性任务不可重试；每日任务恢复只影响未来计划。
