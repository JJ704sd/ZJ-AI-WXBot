# Windows 附件预览

在消息附件中点击“打开预览”。附件须已下载到本机并通过现有消息关联、账号及读取范围检查。

| 格式 | 预览能力 |
| --- | --- |
| PDF | 保留已有 PDF.js 分页渲染 |
| DOCX | 正文段落与表格；不还原图片、页眉和精确分页 |
| XLSX | 工作表切换、单元格地址与原始值；不计算公式，日期可能显示序号 |
| MD | 标题、无序列表、引用、粗体、行内代码与代码块；HTML 作为文本，不加载外部图片 |
| TXT / CSV / JSON / LOG | 文本预览，支持 UTF-8 和 GB18030 |
| DOC / XLS | 明确提示暂不支持内嵌预览，可下载或另存为新格式 |

新增解析只在本机运行，无新增生产依赖。预览上限 20 MB，Office 解压总量上限 24 MB；Word 最多 1000 个段落/表格，每表 200 行、50 列；Excel 最多 20 张表，每表 200 行、每行 50 个单元格；文本最多 200000 字符。完整原文件仍可下载。
