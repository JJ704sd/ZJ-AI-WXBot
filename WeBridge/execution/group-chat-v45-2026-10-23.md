# 群聊 v45 / Skill 1.31.0：指定导出位置

用户已确认选择本机目录并记住位置。个微、企微群聊均实现，私聊交付仍为 1.7.0。

## 使用

1. 在群聊导出区域点击“选择位置…”，选择本机文件夹。界面展示完整路径，并记住本客户端的上次选择。
2. 解析并人工复核后，点击“一键导出所选群”。每次在所选目录下新建独立批次，记录、媒体、附件、复核记录和分析材料一起保存。
3. 已导出的当前群，可在“打开文件 → 另存当前群到指定位置…”保存完整副本。此操作复用已确认的材料，校验原导出，不需要重新解析；原文件和正式进度保留。

新导出直接写到所选目录，不先在默认导出目录生成另一份。已完成的旧导出保留原位置；更换目录后仍可恢复和修复此前位置的批次。恢复最近批次按批次时间名称排序，避免不同父目录名称影响定位。
