## 明确错误及判定

上游错误说明（省略数据库地址）：

> 自动注册管理员密钥失败: 查找系统用户失败: server selection error: context deadline exceeded … dial tcp [上游数据库地址]:27017: i/o timeout

这次请求确实到达授权服务，并在服务端自动注册管理员密钥、查询系统用户时因其数据库连接超时失败。该响应指向上游数据库依赖，不是本机MySQL/Redis故障，也不是明确的付费或密钥无效提示。不连接或探测错误中披露的数据库地址。

11.281秒的实际响应也解释了为什么固定EXE的5秒HTTP等待无法取得这条错误；不是通过更改本地Count/Days就能解除。结论仅适用于本轮，不能追溯断定此前未知请求均相同失败。此前所有未知状态仍保留。
