# 方案进度与卡点台账

更新日期：2026-09-21｜配套 v1.12｜代码基线 ff7dcd5。

已有局部受控普通文本收发；稳定身份、真实 @、连续事件、业务交接与 300 群仍未完整验收。业务允许调整个微账号并优先保留现有群。依据与详细限制见[综合报告](agent-personal-wechat-mixed-group-feasibility-report-2026-09-16.md)。

## 1. 方案范围与当前定位

沿用附件 A01—A18 分类，新增 A19、A20；不强行把两家供应商归入 legacy 861、MAX 或 Cloud。

| 编号／路线 | 当前定位 | 决定下一步的缺口 |
|---|---|---|
| A01 个微数据库＋独立发送 | 局部读取成立 | 真实增量覆盖、身份及同路线发送联调 |
| A02 企微本地库＋跨账号发送 | 参考方案 | 数据权限、跨账号群／成员映射和真实采样 |
| A03 原生 UIA／wxauto | 本机语义结构受限 | 精确客户端与控件；不泛化为所有版本不可行 |
| A04 临时 Qt／pyweixin | 详情探针与独立文本验证分列 | 稳定绑定、状态生命周期、原生 @ |
| A05 UIA＋OCR＋SendInput | 已有局部人工读写 | 可靠事件与目标身份、通用发送保护、连续触发 |
| A06 自研 Hook | 接收路径研究 | 真实执行、覆盖和消息语义关联 |
| A07 既有 Hook SDK | 候选参考 | 精确交付版与原群兼容，不继承旧版本成绩 |
| A08 legacy Windows 861 | 离线适配已有；历史 G1 未过 | 匹配有效设备 key 或适用恢复证据，不断言今日仍故障 |
| A09 MAX／A10 Cloud | 各自独立产品契约 | 授权、真实字段和原群样本；Cloud 历史 502 不与 861 合并归因 |
| A11 GeWe | 本地合成 HTTPS 已验 | 厂商真实回调、部署及送达 |
| A12 StarBot | 文档型候选 | 版本、机制、真实 @、回调契约和具体权益 |
| A13 Wechaty＋PadLocal | 生态备选 | 现行服务资格及目标群契约 |
| A14 传统 Webhook | 适用群的输出组件 | 无完整普通消息输入，非直接个微接管 |
| A15 企微智能机器人／CLI | 替代入口候选 | 不能一概称单向；须验证目标会话范围及迁移配合 |
| A16 存档／CA／企业分析 | 企业侧分析候选 | 数据权限、模型位置、个人号输出另解 |
| A17 openclaw-weixin | 既有研究的直接会话路线 | 附件记录 chatTypes=direct，不当作目标混合群验收 |
| A18 微信客服／对话平台 | 分产品评估的替代入口 | 不把客服接待能力当原混合群能力；具体产品待核 |
| A19 wechat2ipad 付费协议 | 已取得接口定义的连接层候选 | 入站 @ 契约、双向真实提醒、发送状态、业务员共存及规模 |
| A20 WeChatDataAnalysis 付费版 | GUI／纯接口供应商声明 | 私有 API、混合群身份与 @、运行方式及交付权益 |

A14—A18 按新需求可进入替代方案比较，不再仅因“非原账号”永久排除；仍须单列业务关系与入口变化，不能标记已满足首选个微路径。旧路线细节和历史商业资料见[历史 v1.6](agent-feasibility-v1.6-historical-2026-09-18.md)及附件 v1.11，本轮未重验全部外部产品。


## 2. 当前卡点与下一条有效证据

| 优先项 | 已知缺口 | 可解除的证据 |
|---|---|---|
| 业务配置 | 执行日／窗口、联系人数量、话术、@所有人、负责人通知、入站峰值未定 | 配置清单和批准场景；不为这些参数编造默认业务承诺 |
| 连接契约 | A19 入站 @／发送状态不清；A20 私有接口缺失 | 脱敏原始事件、群／成员／发送样例、错误码、版本和权益 |
| 双向原生 @ | 无付费候选目标群实测 | 两类成员分别 @ 接管账号并被准确识别；接管账号分别 @ 两类成员且收到原生提醒 |
| 身份与事件 | 标题／OCR／局部读取不能覆盖改名、重复、重连 | 稳定群／成员及事件依据、本人排除、同文不同事件、历史边界与补收 |
| 人工接管 | 不能把后台日志算交接完成 | 负责人收到待办、可定位原消息、暂停生效、关闭与恢复；通知失败不声称已转交 |
| 提交不确定 | 不同接口成功含义未知 | 区分未提交、已受理、结果不明、接收验证；unknown 先核查，不换路盲目补发 |
| 连续与规模 | 片段成功未覆盖 300 群 | 明确账号分布／执行窗口／入站负载后，分阶段扩群，保留计划任务分母与实际结果 |
