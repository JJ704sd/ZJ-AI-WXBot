# 个微收发

# 一、项目目标与验证链路

**项目目标：** 个人微信账号在混合业务群中完成“识别目标群与成员 → 接收消息和真实 @ → 按批准规则处理 → 定时索价或受控回复 → 发回原群并真实 @ 指定成员”，最终再验证约 300 群的运行、恢复与维护能力。价格承诺、订单确认及超范围事项仍交人工。

**当前判断：** 已有单账号、小范围真实 MVP 摘要，但没有任何一个付费 SKU 能直接继承这些项目成绩。供应商“有接口”只代表具备候选基础，不等于本项目已完成真实验收。

### 1.1 PoC 验证流程

| 步骤 | 要验证什么 | 对应功能 |
|---|---|---|
| ① 进入正确账号与群 | 核对账号，准确绑定目标群和目标成员 | F1、F2 |
| ② 接收并辨认输入 | 读取新消息，识别群、发送者、自消息、重复与真实被 @ 对象 | F3、F7a |
| ③ 决定何时、回复什么 | 定时索价；被真实 @ 后按批准范围处理；超范围交人工 | F6、F7 业务流程 |
| ④ 发回原群并提醒目标人 | 发送批准正文，真实 @ 指定成员并核对接收端提醒 | F4a、F5a、F5b |
| ⑤ 接口接入与安全停发 | 统一事件、发送、身份、去重、审批、暂停和结果不明处理 | F8、F11 |
| ⑥ 扩展与持续运行 | 按需处理媒体/撤回/合并记录，再验证多群、恢复与长期运行 | F9、F10、F12 |

### 1.2 F1-F12 功能与必要性

**必＝项目必须实现；非＝供应商原生能力非必须；条＝纳入对应业务范围或选择该路径时必须。**

| 功能 | 主要含义 | 必须性 |
|---|---|---|
| F1 | 供应商扫码/登录控制 | **非**，可人工登录，但账号核对始终必须 |
| F2 | 群及成员列表/准确绑定 | F2a **条**；准确绑定 F2b **必** |
| F3 | 群消息读取、来源与去重 | **必** |
| F4 | F4a 原群发文本；F4b 无点击+服务端回执 | F4a **必**；F4b **非** |
| F5 | 指定成员原生 @；混合群企微成员真实提醒 | **必** |
| F6 | 供应商内置定时 | **非**；项目定时流程本身必须 |
| F7 | F7a 入站真实 @ 对象；F7b 内置固定回复 | F7a **必**；F7b **非** |
| F8 | 退出接口/可靠停发 | 退出 API **条**；可靠停发 **必** |
| F9 | 图片、文件、视频与附件下载 | **条** |
| F10 | 撤回通知、合并记录展开 | **条** |
| F11 | 事件输入+发送调用+完整 Agent 契约 | **必**，可由我方 Adapter 补齐 |

# 三、交付方式与成本

## 3.1 常见交付模式

| 你实际买到的东西 | 怎么接 | 谁负责运行 | 常见收费方式 |
|---|---|---|---|
| **托管 API / SaaS** | 我方用 HTTP/Webhook 调供应商服务 | 供应商运行接入层，我方负责业务系统 | 按号/月、按号/年、套餐、在线天数 |
| **本地桌面 SDK / RPA** | Windows 微信客户端常驻，本机 SDK 控制/监听 | 我方维护电脑、客户端与运行环境 | 按电脑、激活码、开发者授权或待报价 |

| **运营工作台 / SCRM** | 直接使用现成界面；部分套餐另带 API | 供应商运行平台，我方使用运营流程 | 按号/年、坐席/账号、模型额度或组合套餐 |

### 3.4 项目成本构成

**项目总成本 = 许可证/订阅 + 部署与运行资源 + Adapter/审批/调度等接入开发 + 模型与人工运营 + 后续升级维护。**

约 300 个业务群不能直接乘“元/号”；先确认这些群实际分布在哪些微信账号、电脑、设备实例或 Key 上，再按供应商计费对象计算。

### 3.5 采购前确认清单

1. 具体购买的 **SKU、交付版本和适配微信客户端版本** 是什么？
2. 是否支持本项目的 **个人微信混合群**，能否提供对应群型的实际样例？
3. 群消息是否能结构化识别 **发送者、群 ID、真实 @ 对象**？
4. 指定成员 @ 在混合群里能否让 **企微成员实际收到原生提醒**？能否安排 PoC？
5. 事件回调、发送调用、消息 ID、鉴权、限流和发送状态分别是什么契约？
6. 按 **账号/电脑/设备/节点/Key/在线天** 中哪一种计费？最低购买量和迁移换绑规则是什么？
7. 使用期、更新期、维保期各多久？微信升级后适配、故障响应和恢复怎么收费？
8. 是否包含 API、部署、源码、SCRM、模型额度和技术支持？退出后数据删除/迁移如何处理？
